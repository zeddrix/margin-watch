### Decisions made

Full entries (why, alternative) are in `docs/decisions.md`:

1. The AI never does maths.
2. The default AI provider is a scripted demo model.
3. Mail is dry-run only.
4. The dashboard reads static run files.
5. Percentages are stored in percent units
6. Display money is whole dollars, rounded half-up; files keep cents.
7. NEEDS_REVIEW check order: cost centres → sell → costs → percent complete (missing, out of range, 0% with spend).
8. NEEDS_REVIEW jobs get no metrics at all
9. Missing sell or missing costs are NEEDS_REVIEW, not file errors
10. Main driver only for LOSS / AT_RISK / WATCH, and only if some overrun is above $0.
11. Overrun % is null when the estimate is $0
12. "Jobs needing action" = LOSS + AT_RISK.
13. Average forecast margin is sell-weighted
14. `--as-of` defaults to the file's `snapshot_date`.
15. Job ids are Simpro-style numbers ("1042").
16. `compute_metrics` states its precondition with `assert`
17. Coverage is enforced on every pytest run
18. Dates are formatted with explicit English day/month names
19. Run JSON carries numbers, not strings
20. `--generated-at` and `--output-dir` CLI options.
21. `--ai off` records `fallback_reason: "ai_off"`.
22. The run index is updated in place
23. Subject line counts LOSS, AT_RISK and NEEDS_REVIEW
24. Template summary leads with "Call {PM} about {id} {name}."
25. Excel stores percentages as fractions with a `0.0%` format
26. A usage error (bad `--as-of`, unknown `--ai`) exits 2
27. Claude request: no `temperature`, `thinking: {"type": "between_tools"}`, `max_tokens` 500.
28. The validator compares canonical tokens:
29. The allow-list is every number in the run's facts
30. `demo-bad` invents `$13,750`
31. Fallback reasons:
32. No server-side refusal fallback (`fallbacks` beta) on the Claude request.
33. "No key" means `ANTHROPIC_API_KEY` is empty
34. `agent/.env` is loaded by the CLI only, never overriding real env vars
35. The demo's phrasing varies per job by SHA-256 of the job id
36. Dashboard E2E tests intercept `runs/*.json` and serve the committed fixtures
37. The dashboard is a client-rendered single page (`ssr = false`, prerendered shell, adapter-static)
38. Risk order is recomputed in the browser with the agent's rule
39. Dashboard deltas (since last run) are computed in TypeScript from the run files' numbers
40. "Call today" list in the summary card
41. SvelteKit 3.1 / Svelte 5 / Vite 8 / Tailwind 4
42. Playwright runs on port 4174
43. `make demo` simulates the two scheduled 6:30 AM runs
44. `scripts/check_frozen_tests.py`
45. CI uses Node 24 LTS and Python 3.12 via uv
